## generate

Optionally generates a cited answer from explicitly supplied, revision-scoped evidence.

**Choose this tool:** Draft a cited answer only after selecting trustworthy retrieval evidence.

**Side effects:** Invokes the configured HTTP generation provider or host MCP sampling. Sends the supplied prompt and evidence to that provider.

**Approval:** Workspace authorization applies. Indexing roots, storage, and generation capability remain separate from filesystem grants.

**Output:** Returns status, generated answer, citations, and failure reason where applicable. Tool failures use the existing structured error envelope; inspect its code, retryability, and suggested next call.

**Important failures:** Disabled providers, unsupported sampling, absent secrets, rejected evidence, timeouts, and unavailable providers do not produce a trusted answer.

<ToolParameters name="generate" />

```json
{
  "name": "generate",
  "arguments": {
    "workspaceId": "workspace:v1:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
    "prompt": "Explain this evidence.",
    "allowedCorpusArtifactIds": [
      "source:v1:dddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddd"
    ],
    "evidence": [
      {
        "artifactId": "source:v1:dddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddd",
        "entityId": "graph-node:v1:bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb",
        "path": "src/index.ts",
        "range": {
          "startByte": 0,
          "endByte": 1,
          "start": {
            "line": 0,
            "column": 0
          },
          "end": {
            "line": 0,
            "column": 1
          }
        },
        "text": "x"
      }
    ]
  }
}
```

## retrieve

Ranks revision-scoped exact, lexical, semantic, and graph evidence within explicit budgets.

**Choose this tool:** Find source evidence by terms, symbols, filters, and optional semantic scoring.

**Side effects:** Reads a published generation. Semantic scoring may load configured embedding artifacts.

**Approval:** Workspace authorization applies. Indexing roots, storage, and generation capability remain separate from filesystem grants.

**Output:** Returns ranked path, range, text, identity, freshness, semantic state, and coverage evidence. Tool failures use the existing structured error envelope; inspect its code, retryability, and suggested next call.

**Important failures:** An absent or stale generation, disabled semantic support, model failure, or degraded coverage limits conclusions.

<ToolParameters name="retrieve" />

```json
{
  "name": "retrieve",
  "arguments": {
    "workspaceId": "workspace:v1:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
    "query": "Where is configuration generation validated?"
  }
}
```
