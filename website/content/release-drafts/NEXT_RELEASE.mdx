## Release qualification

The release workflow now benchmarks the qualified Linux x64 executable before publication. Later releases compare with the preceding stable release on the same runner. Each release includes a comparison table and charts. Available since NEXT_RELEASE.

## Documentation navigation

Tool reference pages highlight the selected heading when you follow a section link or navigate through browser history. Scrolling resumes the automatic highlighting. Available since NEXT_RELEASE.
